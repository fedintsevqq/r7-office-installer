# Старые версии скриптов

Здесь лежат монолитные установщики версии 5.2 — те, что были до появления универсального `install-r7.sh`.

Каждый файл содержал всю логику целиком и работал только со своей системой. Пути, имена пакетов и особенности вроде Wayland были зашиты прямо в код, поэтому под каждую ОС приходилось держать отдельную копию.

```
astra/update-r7-astra.sh      Astra Linux
debian13/update-r7.sh         Debian 13
redos/update-r7-redos.sh      РЕД ОС
```

Рядом — Word-инструкция, по которой эти скрипты запускали.

Ничего из этой папки в работе больше не нужно. Она сохранена, чтобы можно было заглянуть в старую логику и сверить поведение, если новый скрипт где-то поведёт себя иначе. Для установки берите `install-r7.sh` из корня репозитория.

## Осторожно с astra и redos

Файлы `astra/update-r7-astra.sh` и `redos/update-r7-redos.sh` — не сами скрипты, а установщики скриптов. Первая строка у них `cat > /usr/local/bin/... << 'EOF'`: при запуске файл целиком выгружается в `/usr/local/bin`. Запускать их напрямую как установщик Р7 бессмысленно.

Вдобавок в astra-версии сломан вложенный heredoc: внутренний `cat << EOF` в справке (строка 67) закрывает внешний блок раньше времени, и `bash -n` на файле падает. Чинить не стали — файл лежит здесь как исторический снимок, а не как рабочий инструмент.
