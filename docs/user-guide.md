# Руководство пользователя

Как поставить и обновить Р7-Офис на Linux. Написано для тех, кто редко работает с терминалом.

---

## Что понадобится

1. Файл дистрибутива Р7-Офис. На Debian и Astra это `.deb`, на Альт и РЕД ОС — `.rpm`.
2. Пароль администратора (root или sudo).
3. MD5-сумма сборки — она обычно указана в документе Word, который приходит вместе с дистрибутивом. Не обязательна, но с ней спокойнее.

---

## Установка за четыре шага

### Шаг 1. Положите файлы в одну папку

Скопируйте `install-r7.sh` и дистрибутив Р7 в любую папку. Например, в «Загрузки».

Скрипт сам поищет пакеты по порядку: рядом с собой, в `~/Downloads`, в `~/Загрузки`, в `/home/administrator/Downloads`, в `/opt/r7-dist`.

### Шаг 2. Разрешите запуск

Откройте терминал в этой папке и выполните:

```bash
chmod +x install-r7.sh
```

Это делается один раз.

### Шаг 3. Запустите

```bash
sudo ./install-r7.sh
```

Система спросит пароль. Вводите — символы на экране не появятся, это нормально.

### Шаг 4. Выберите версию в меню

Скрипт покажет, что нашёл:

```
  ДОСТУПНЫЕ ДИСТРИБУТИВЫ (2):
  [1] r7-office_8.1.0-1234_amd64.deb  312M  (самая новая)
  [2] r7-office_8.0.2-987_amd64.deb   309M  ✓ УСТАНОВЛЕНА
```

Нажмите `1` и Enter. Скрипт спросит MD5 — введите его из документа Word или нажмите Enter, чтобы пропустить проверку.

Дальше он сам поставит библиотеки, закроет открытый Р7 и установит новую версию. Обычно это занимает две-три минуты.

---

## Пункты меню

| Клавиша | Что делает |
|---|---|
| `1`, `2`, `3`... | поставить версию под этим номером |
| `L` | поставить самую новую версию из папки |
| `F` | переустановить ту версию, что уже стоит |
| `S` | fast-lane: всё автоматически, без вопросов |
| `D` | заново проверить и доставить библиотеки |
| `W` | починить запуск под Wayland |
| `P` | оптимизация RDP (только РЕД ОС) |
| `H` | диагностика системы |
| `C` | очистить кэш редактора |
| `G` | показать список библиотек и их состояние |
| `R` | удалить Р7-Офис |
| `?` | справка прямо в меню |
| `Q` | выход |

---

## Когда какой пункт нужен

**`F` — переустановить текущую версию.** Р7 стоял и работал, а теперь не открывается или падает при запуске. Переустановка поверх чинит битые файлы, не трогая ваши документы и настройки.

**`C` — очистить кэш.** Р7 подвисает, долго открывает файлы, показывает пустые вкладки. Кэш накапливает мусор, чистка помогает.

Важно: в кэше лежат автосохранённые документы из папки `recover`. Если вы теряли несохранённый файл и надеетесь его достать — сначала загляните туда, а чистите потом.

**`D` — переустановить зависимости.** Р7 установился, но не запускается и в терминале пишет что-то вроде `error while loading shared libraries`. Значит, не хватает библиотеки.

**`W` — починить Wayland.** Актуально для Debian 13. Признаки: Р7 запускается, но окно пустое, серое или не реагирует на клавиатуру.

**`H` — диагностика.** Когда непонятно, что сломалось. Покажет всё разом: версию, библиотеки, сессию, место на диске.

## Проверка MD5

MD5 — это отпечаток файла. Если дистрибутив скачался с ошибкой или его подменили, отпечаток не совпадёт.

Возьмите MD5 из документа Word и вставьте в терминал, когда скрипт попросит. Вставка в терминале — `Ctrl+Shift+V`, обычный `Ctrl+V` там не работает.

Совпало — установка продолжится. Не совпало — скрипт остановится и покажет обе суммы:

```
❌ MD5 НЕ совпадает!
   Ожидалось: a1b2c3d4e5f6...
   Получено:  f6e5d4c3b2a1...
```

Так бывает по двум причинам: файл скачался не полностью или вы ввели сумму от другой версии. Скачайте дистрибутив заново.

Если MD5 у вас нет — просто нажмите Enter. Проверка пропустится, установка пойдёт дальше.

## Установка без меню

Когда нужно поставить Р7 на десяток машин, меню только мешает.

```bash
# самая новая версия, никаких вопросов
sudo ./install-r7.sh -f -y

# конкретная версия с проверкой
sudo ./install-r7.sh -v 8.1.0-1234 --md5 a1b2c3d4e5f6

# дистрибутивы лежат на сетевой шаре
sudo ./install-r7.sh --dir /mnt/share/r7 -l -y
```

Хотите сперва посмотреть, что произойдёт? Добавьте `--dry-run` — скрипт покажет команды и ничего не выполнит.

---

## Графический режим

Если терминал непривычен:

```bash
sudo ./install-r7.sh --gui
```

Откроются обычные окна: список версий, поле для MD5, полоса прогресса. Нужен `zenity` — если его нет, скрипт предложит поставить.

## Частые проблемы

### «Этот скрипт должен запускаться от root»

Забыли `sudo`. Правильно: `sudo ./install-r7.sh`.

### «bad interpreter: No such file or directory»

Файл прошёл через Windows и получил другие переносы строк. Лечится одной командой:

```bash
sed -i 's/\r$//' install-r7.sh
```

### «Permission denied»

Не выставлены права на запуск:

```bash
chmod +x install-r7.sh
```

### «В папке не найдено файлов r7-*.deb»

Скрипт ищет файлы, чьё имя начинается на `r7-`. Проверьте, что дистрибутив лежит рядом и называется как положено. Либо укажите папку прямо:

```bash
sudo ./install-r7.sh --dir /полный/путь/к/папке
```

### Р7 установился, но не запускается

Сначала диагностика:

```bash
sudo ./install-r7.sh --health
```

Смотрите блок «Зависимости». Если там красные строки — выберите в меню `D`.

Если сессия Wayland — выберите `W`.

### Под Wayland окно пустое

```bash
sudo ./install-r7.sh --fix-wayland
```

После этого запускайте Р7 из меню приложений — ярлык уже переделан.

Не помогло? Выйдите из системы и на экране входа нажмите шестерёнку рядом с полем пароля. Выберите «GNOME на Xorg» и зайдите снова.

### Р7 по RDP страшно тормозит

Только на РЕД ОС: пункт `P` в меню, вариант 1.

Учтите: оптимизация отключает шифрование RDP. Для локальной сети это приемлемо, для подключения через интернет — нет.

Передумали — тот же пункт `P`, вариант 2, вернёт исходные настройки.

### Установка прервалась на середине

Посмотрите журнал:

```bash
tail -50 /var/log/r7-update.log
```

Последние строки покажут, на чём споткнулось. Чаще всего это нет места на диске или недоступен репозиторий.

## Удаление Р7-Офис

Пункт `R` в меню или:

```bash
sudo ./install-r7.sh --remove
```

Три варианта:

1. **Удалить программу, оставить данные.** Настройки и автосохранённые документы на месте. Поставите Р7 заново — всё вернётся как было.
2. **Удалить программу и почистить кэш.** Настройки остаются, временные файлы стираются.
3. **Полное удаление.** Уходит всё: программа, настройки, кэш, ярлыки. Скрипт попросит ввести `YES` заглавными — защита от случайного нажатия.

---

## Куда смотреть, если ничего не помогло

Соберите два файла и отправьте их администратору:

```bash
sudo ./install-r7.sh --health > /tmp/r7-health.txt
cp /var/log/r7-update.log /tmp/r7-log.txt
```

В `/tmp/r7-health.txt` будет состояние системы, в `/tmp/r7-log.txt` — история всех действий.
